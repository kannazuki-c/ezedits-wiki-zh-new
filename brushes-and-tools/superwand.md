# 超级魔杖

超级魔杖工具提供四种不同的点选择和操作模式，为使用区域选区提供了一种扩展的方式。

**强烈推荐 WorldEditCUI：** [**https://modrinth.com/mod/worldedit-cui**](https://modrinth.com/mod/worldedit-cui)

### 模式

1. <mark style="color:orange;">**TRACE 模式**</mark>：选择你正在瞄准的方块。
2. <mark style="color:orange;">**POSITION 模式**</mark>：选择你当前玩家位置处的方块。
3. <mark style="color:orange;">**RELATIVE 模式**</mark>：选择相对于最后放置的点和玩家瞄准方向的一个点。
4. <mark style="color:orange;">**GRAB 模式**</mark>：启用抓取和移动一个点或整个选区的功能。

### 控制

* <mark style="color:blue;">**右键点击**</mark>：
  * 在点选择模式中，选择一个新点或在选区已满时替换最近的点。
  * 在 GRAB 模式中，拾起一个点或整个选区，随着玩家的移动而移动。
* <mark style="color:blue;">**左键点击**</mark>：
  * 在点选择模式中，移除最后设置的点。
  * 在 GRAB 模式中，放下该点或选区。
* <mark style="color:blue;">**潜行 + 左键点击**</mark>：循环切换工具模式。
* <mark style="color:blue;">**交换手（默认 F 键）**</mark>：反转选区中的点的顺序。
* <mark style="color:blue;">**潜行 + 交换手（默认 F 键）**</mark>：将所有凸选区的点沿点列表中的一个位置移动。
